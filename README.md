# TelDeck Downloads

This repository contains TelDeck Windows installers and update packages only.

- New installation: download `TelDeck-Setup.exe` from the [latest release](https://github.com/TunahanMuratl/Teldeck-Downloads/releases/latest).
- Existing installation: use **Güncellemeleri denetle** in the TelDeck desktop client. Updates are verified with the matching SHA-256 file.

The TelDeck source repository is private. This repository does not contain application source code.
